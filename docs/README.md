# Le dossier docs

Rien ici n'est livré dans l'addon (`.pkgmeta` ignore le dossier). Notes de travail en français ; textes publiés en anglais et en français.

| Où | Quoi |
|---|---|
| `REPRISE-CLAUDE.md` | Démarrage rapide d'une nouvelle session : décisions, pièges, journal. À lire en premier. |
| `A-REPRENDRE.md` | État du projet (version en jeu, branches, points ouverts), pistes suivantes, feuille de route. Court : l'historique daté est dans `archive/`. |
| `IDEES-FUTUR.md` | Idées pour plus tard, rangées par thème (rien n'y est promis). |
| `RELEASE.md` | Comment publier une version (GitHub, CurseForge, Wago). |
| `pages/` | Textes publiés hors de l'addon : description CurseForge et Wago, la même sur les deux (`description.md`), titre, résumé et description GitHub (`summary.md`). |
| `etudes/` | Études et plans : découpage en modules (`PLAN-modules.md`), bloc Farm (`PLAN-bloc-farm.md`), addons de WoW Forever et compatibilité DataBroker (`ADDONS-FOREVER.md`), ce qu'on a appris ailleurs (`SOURCES.md`), fenêtre d'options 1.3 (`PLAN-options-1.3.md`), « Retirer » (`PLAN-retirer-T2.md`), placement au pixel (`PLAN-placer-T2.md`). |
| `archive/` | Historique daté du projet de la 1.0 à la 1.3.1 (`HISTORIQUE-1.0-1.3.md`), plans terminés et anciennes listes de tests. |
| `localization/` | Textes anglais et français de l'addon, une ligne par texte, pour les traducteurs (générés : `tools/export_locales.lua`). |
| `TRANSLATING.md` | Comment traduire Tessera (pull request ou issue « Translation »), en anglais. |
| `art/` | Logo en grand : icône (512 et 1024 px) et nom « Tessera » sur fond clair, sombre ou transparent. Police Outfit (licence OFL). |
| `media/` | Bannière (`banner.png`, et `banner-2x.png` pour CurseForge et Wago) et captures du README. |
