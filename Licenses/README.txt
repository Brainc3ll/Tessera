Licenses of what Tessera ships
==============================

Tessera itself: MIT license (LICENSE-Tessera-MIT.txt, also LICENSE at the root of the repository).

Fonts in Media/Fonts, shipped unchanged. Each one keeps its own license, copied here:

- Atkinson Hyperlegible Next: SIL Open Font License 1.1 (OFL-AtkinsonHyperlegibleNext.txt)
- OpenDyslexic: SIL Open Font License 1.1 (OFL-OpenDyslexic.txt)
- Luciole: Creative Commons Attribution 4.0 (LICENSE-Luciole-CC-BY-4.0.txt)
- Lexend: SIL Open Font License 1.1 (OFL-Lexend.txt)
- Andika: SIL Open Font License 1.1 (OFL-Andika.txt)
- Inclusive Sans: SIL Open Font License 1.1 (OFL-InclusiveSans.txt)
- Cinzel: SIL Open Font License 1.1 (OFL-Cinzel.txt)
- Inter: SIL Open Font License 1.1 (OFL-Inter.txt)

The credits (authors, links) are in the About tab, Licenses chapter, and in README.md.
Tessera embeds no library. LibSharedMedia, LibDBIcon and DataBroker are used only when another
addon provides them.
