# Le dossier docs

Rien ici n'est livré dans l'addon (`.pkgmeta` ignore le dossier). Notes de travail en français ; textes publiés en anglais et en français.

| Où | Quoi |
|---|---|
| `REPRISE-CLAUDE.md` | Démarrage rapide d'une nouvelle session : décisions, pièges, journal. À lire en premier. |
| `A-REPRENDRE.md` | État du projet, ce qui reste à faire, feuille de route des versions. |
| `IDEES-FUTUR.md` | Idées pour plus tard, rangées par thème (rien n'y est promis). |
| `RELEASE.md` | Comment publier une version (GitHub, CurseForge, Wago). |
| `pages/` | Textes publiés hors de l'addon : descriptions CurseForge et Wago (`curseforge-description.md`, `wago-description.md`), titre, résumé et description GitHub (`summary.md`). |
| `etudes/` | Études : découpage en modules (`PLAN-modules.md`), bloc Farm (`PLAN-bloc-farm.md`), addons de WoW Forever et compatibilité DataBroker (`ADDONS-FOREVER.md`), ce qu'on a appris ailleurs (`SOURCES.md`). |
| `archive/` | Plans terminés et anciennes listes de tests. |
| `localization/` | Textes de l'addon envoyés à l'outil de traduction de CurseForge (générés : `tools/export_locales.lua`). |
| `art/` | Logo en grand : icône (512 et 1024 px) et nom « Tessera » sur fond clair, sombre ou transparent. Police Outfit (licence OFL). |
| `media/` | Bannière (`banner.png`, et `banner-2x.png` pour CurseForge et Wago) et captures du README. |
