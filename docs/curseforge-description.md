# Tessera

**Customizable information and launcher blocks that merge like mosaic tiles.**

Tessera shows small blocks with the information you want (gold, bags, durability, FPS, latency, time, XP, professions, mail...) and turns minimap buttons into blocks too. Place them anywhere: blocks dropped against each other merge into a single frame, like the tiles (*tesserae*) of a mosaic.

Made for **WoW Forever**. English and French.

## Features

- **More than 35 information blocks**: gold (with a 7-day history and your characters' gold), bags (with junk value), durability, FPS and latency (with graphs), local and server time, XP and rested XP, coordinates, zone, friends, guild, group, quests, reputation, currencies, one block per profession, weapon skills, talents, Legacy points, hearthstone, mail, whispers, reagents, ammo, item level, speed, volume, instances, played time, a personal goal...
- **Made for WoW Forever's own systems**: a **Legacy points** block (your points on the Legacy track, the next reward and every reward in its tooltip, a click opens the Legacy panel), **weapon skills** read from Forever's skill list, and profession, talent and Legacy blocks that open Forever's own windows.
- **Blocks that hide themselves** when they have nothing to show (mail, whispers, reputation...), in a second row under the main bar.
- **Launcher blocks** made from minimap buttons and addon compartment entries.
- **DataBroker support**:
  - add any DataBroker object of your other addons as a block;
  - share Tessera's blocks with Titan Panel, ChocolateBar, Bazooka and other DataBroker display addons;
  - when such an addon is installed, Tessera switches to a DataBroker mode (your display addon shows Tessera's blocks). This mode is explained on first use and can be turned off at any time, to use both.
- **Merging in every direction**, with alignment guides, snapping (also to Blizzard frames), undo (Ctrl + Z), frozen groups, spacers (empty, separator line or text), global and per-group scale. Blizzard's Edit Mode can unlock the blocks too, and one click brings back blocks lost off screen.
- **Styles** matching FlareUI 2.x and 1.x (the one matching your version is the default), ElvUI, EllesmereUI and Blizzard, plus Clean and Transparent (text and icons only). When a supported interface is installed, Tessera shows its style on sample blocks and offers it; it never changes your style on its own.
- **Per-block settings**: text, frame, icons (same size for all, square or round frame, black and white), opacity, progress bar, color thresholds, show on hover, alerts, Shift + click and middle-click actions.
- **Profiles**: per account or per character, export / import as text, ready-made layouts (top bar, bottom bar, left column, compact), automatic dungeon / raid profile.
- **Accessibility**: colorblind-friendly colors, high contrast, minimum text size.

## Getting started

Type **/tessera** (or **/tes**) to open the options. The **Help** tab explains everything. Click **Unlock blocks** to move them, **Lock** when you are done.

| Command | Effect |
|---|---|
| /tessera | Options |
| /tessera lock / unlock | Lock or unlock the blocks |
| /tessera reset | Back to the default layout |
| /tessera minimap | Show or hide the minimap button |
| /tessera preview | Sample values in every block (for screenshots) |
| /tessera broker | DataBroker mode on or off |
| /tessera recover | Bring back blocks that stick out of the screen |
| /tessera bug | Report to copy into a bug report |

## Bugs and ideas

Type **/tessera bug**, copy the report and post it on the GitHub issue tracker (or in the comments here). Ideas are welcome too.

# Tessera (français)

**Des blocs d'informations et des lanceurs personnalisables qui s'assemblent comme une mosaïque.**

Tessera affiche de petits blocs avec les informations que tu veux (or, sacs, durabilité, FPS, latence, heure, XP, métiers, courrier...) et transforme aussi les boutons de la minicarte en blocs. Place-les où tu veux : des blocs posés les uns contre les autres fusionnent en un seul cadre, comme les tesselles d'une mosaïque.

Conçu pour **WoW Forever**. En anglais et en français.

## Fonctions

- **Plus de 35 blocs d'informations** : or (avec l'historique sur 7 jours et l'or de tes personnages), sacs (avec la valeur des objets gris), durabilité, FPS et latence (avec graphiques), heure locale et du serveur, XP et XP de repos, coordonnées, zone, amis, guilde, groupe, quêtes, réputation, monnaies, un bloc par métier, compétences d'armes, talents, points d'héritage, pierre de foyer, courrier, chuchotements, composants, munitions, niveau d'objet, vitesse, volume, instances, temps de jeu, objectif personnel...
- **Pensé pour les systèmes propres à WoW Forever** : un bloc **Points d'héritage** (tes points sur le parcours Héritage, la prochaine récompense et toutes les récompenses dans son infobulle, un clic ouvre le panneau Héritage), les **compétences d'armes** lues dans la liste de compétences de Forever, et des blocs métiers, talents et héritage qui ouvrent les fenêtres de Forever.
- **Des blocs qui se masquent** quand ils n'ont rien à montrer (courrier, chuchotements, réputation...), dans une deuxième rangée sous la barre principale.
- **Des blocs lanceurs** créés à partir des boutons de la minicarte et du compartiment d'addons.
- **Support DataBroker** :
  - ajoute en bloc n'importe quel objet DataBroker de tes autres addons ;
  - partage les blocs de Tessera avec Titan Panel, ChocolateBar, Bazooka et les autres addons d'affichage DataBroker ;
  - quand un tel addon est installé, Tessera passe en mode DataBroker (ton addon d'affichage montre les blocs de Tessera). Ce mode est expliqué à la première utilisation et se désactive à tout moment, pour utiliser les deux.
- **Fusion dans tous les sens**, avec guides d'alignement, aimantation (aussi aux cadres de Blizzard), annulation (Ctrl + Z), groupes figés, espaces (vide, ligne de séparation ou texte), échelle globale et par groupe. Le mode Édition de Blizzard peut aussi déverrouiller les blocs, et un clic ramène les blocs perdus hors de l'écran.
- **Styles** assortis à FlareUI 2.x et 1.x (celui de ta version est choisi par défaut), ElvUI, EllesmereUI et Blizzard, plus Épuré et Transparent (seulement le texte et les icônes). Quand une interface prise en charge est installée, Tessera montre son style sur des blocs d'exemple et te le propose ; il ne change jamais ton style tout seul.
- **Réglages par bloc** : texte, cadre, icônes (même taille pour toutes, cadre carré ou rond, noir et blanc), opacité, barre de progression, couleurs de seuil, affichage au survol, alertes, actions du Maj + clic et du clic milieu.
- **Profils** : par compte ou par personnage, export / import en texte, dispositions toutes prêtes (barre en haut, barre en bas, colonne à gauche, compacte), profil automatique en donjon / raid.
- **Accessibilité** : couleurs pour daltoniens, contraste renforcé, taille de texte minimale.

## Pour commencer

Tape **/tessera** (ou **/tes**) pour ouvrir les options. L'onglet **Aide** explique tout. Clique sur **Déverrouiller les blocs** pour les déplacer, puis sur **Verrouiller** quand tu as fini.

| Commande | Effet |
|---|---|
| /tessera | Options |
| /tessera lock / unlock | Verrouiller ou déverrouiller les blocs |
| /tessera reset | Revenir à la disposition de base |

| /tessera preview | Valeurs d'exemple dans tous les blocs (pour les captures) |

| /tessera recover | Ramener les blocs qui dépassent de l'écran |
| /tessera bug | Rapport à copier dans un signalement de bug |
